<p>This page explains the special formatting and functions used across the tool.</p>

<h2>Templating Engine</h2>
<p>The tool uses the <a href="https://ejs.co/" target="_blank" rel="noopener noreferrer">EJS (Embedded JavaScript)</a> templating engine. This means you can write standard HTML and embed JavaScript function calls to display dynamic game data.</p>
<p>The tool pulls data directly from the <a href="https://github.com/RogueSnail/hellclock-data-export/tree/main" target="_blank" rel="noopener noreferrer">official data export</a> to have consistent and always up to date data.</p>

<h2>Linking Between Pages</h2>
<p>You can create links to other pages using standard HTML <code>&lt;a&gt;</code> tags.</p>

<p><b>Syntax:</b></p>
<code>&lt;a href="?page=Page_Name"&gt;Display Text&lt;/a&gt;</code>

<p><b>Examples:</b></p>
<ul>
    <li><code>&lt;a href="?page=MainPage"&gt;Main Page&lt;/a&gt;</code> will create a link to the main page.</li>
</ul>

<h2>External Links</h2>
<p>You can create links to external websites using a standard HTML <code>&lt;a&gt;</code> tag with the <code>target="_blank"</code> attribute.</p>

<p><b>Syntax:</b></p>
<code>&lt;a href="URL" target="_blank" rel="noopener noreferrer"&gt;Display Text&lt;/a&gt;</code>

<h2>Headings</h2>
<p>You can create section headings with standard HTML heading tags (<code>&lt;h2&gt;</code>, <code>&lt;h3&gt;</code>, etc.).</p>

<p><b>Syntax:</b></p>
<pre><code>&lt;h2&gt;Level 2 Heading&lt;/h2&gt;
&lt;h3&gt;Level 3 Heading&lt;/h3&gt;</code></pre>

<h2>Dynamic Content with EJS</h2>
<p>Dynamic content is generated by calling asynchronous JavaScript functions within EJS tags. The main tag you will use is <code>&lt;%- await functionName(arguments) %&gt;</code>. The hyphen <code>-</code> after the opening tag ensures the returned HTML is not escaped.</p>
<p>All game data (<code>allRelics</code>, <code>allAffixData</code>, <code>allTCs</code>, <code>allDungeons</code>, <code>allSkills</code>) is available within the EJS scope.</p>

<h3>Relic Lists</h3>
<p>To display a table of relics, use the <code>createRelicListTemplate()</code> function.</p>
<p><b>Syntax:</b></p>
<code>&lt;%- await createRelicListTemplate(allRelics, allAffixData, { keys: [...], filter: value, ... }) %&gt;</code>
<p>The third argument is an options object. The <code>keys</code> property is an array of strings for the columns to display. Other properties act as filters.</p>
<ul>
    <li><b>keys</b>: Common keys include: <code>icon</code>, <code>name</code>, <code>eRelicSize</code>, <code>type</code>, <code>devotionAffinity</code>, and <code>intrinsicAffixes</code>.</li>
    <li><b>unique</b>: Set to <code>true</code> to show only unique relics.</li>
    <li><b>nonUnique</b>: Set to <code>true</code> to show only non-unique relics.</li>
    <li><b>uber</b>: Set to <code>true</code> to filter for Uber relics.</li>
    <li><b>nightmare</b>: Set to <code>true</code> to filter for Nightmare relics.</li>
    <li><b>ids</b>: An array of relic IDs to display. E.g., <code>[11, 12, 23]</code>.</li>
</ul>

<h3>Treasure Class Lists</h3>
<p>To display a table of all treasure classes, use the <code>createTreasureClassListTemplate()</code> function.</p>
<p><b>Syntax:</b></p>
<code>&lt;%- await createTreasureClassListTemplate(allTCs, ['key1', 'key2']) %&gt;</code>
<p>Available keys include: <code>name</code>, <code>id</code>, <code>type</code>, <code>amount</code>.</p>

<h3>Dungeon Lists</h3>
<p>To display a table of all dungeons, use the <code>createAllDungeonsListTemplate()</code> function.</p>
<p><b>Syntax:</b></p>
<code>&lt;%- await createAllDungeonsListTemplate(allDungeons, ['key1', 'key2']) %&gt;</code>
<p>If no keys are provided, it will default to showing <code>name</code>, <code>sharedShrines</code>, and <code>locations</code>. Available keys include: <code>id</code>, <code>name</code>, <code>internalName</code>, <code>sharedShrines</code>, <code>locations</code>.</p>

<h3>Single Item Info Boxes</h3>
<p>These functions render the full detail infobox for a single item, as seen on the dynamically generated item pages.</p>
<ul>
    <li><code>&lt;%- await createRelicTemplate(relic, allAffixData, allSkills) %&gt;</code> - Renders a relic's infobox (icon, affixes, size, devotion affinity, etc.).</li>
    <li><code>&lt;%- await createTreasureClassTemplate(tc, allTCs, allRelics) %&gt;</code> - Renders a Treasure Class's infobox (contents, weights, sub-classes).</li>
    <li><code>&lt;%- await createDungeonTemplate(dungeon) %&gt;</code> - Renders a dungeon's infobox (floors and their drop configuration).</li>
</ul>

<h3>Relic Drop Chance Lookups</h3>
<p>These functions calculate and display where a relic can drop, taking the sidebar's devotion points into account when computing "Your Chance". They expect a <code>devotionPoints</code> object (e.g. <code>{ furyPoints, faithPoints, disciplinePoints }</code>), which the parser automatically supplies as the <code>devotionPoints</code> variable on relic pages.</p>
<ul>
    <li><code>&lt;%- await createRelicByBossTemplate(relic, allDungeons, allTCs, allRelics, devotionPoints) %&gt;</code> - Shows drop chances grouped by campaign dungeons, other campaign dungeons, and Endless Nightmare tiers. This is used on the auto-generated relic pages.</li>
    <li><code>&lt;%- await createRelicInDungeonTemplate(relic, allDungeons, allTCs, allRelics, devotionPoints) %&gt;</code> - An alternate, simpler list of dungeons that can drop the relic.</li>
    <li><code>&lt;%- await createRelicInTreasureTemplate(relic, allTCs, allRelics) %&gt;</code> - Lists the Treasure Classes that can directly or indirectly drop the relic.</li>
</ul>

<h3>Treasure Class Reverse Lookup</h3>
<p>To find every dungeon that references a given Treasure Class, use <code>createDungeonListTemplate()</code>.</p>
<p><b>Syntax:</b></p>
<code>&lt;%- await createDungeonListTemplate(allDungeons, tc) %&gt;</code>

<h2>Dynamically Generated Pages</h2>
<p>Pages for specific items (relics, dungeons, treasure classes) are generated dynamically based on the URL. For example, visiting <code>?page=relics/Tempest</code> will automatically generate the page for the relic named "Tempest".</p>
<p>The item type comes from the first URL path segment (<code>relics</code>, <code>dungeons</code>, or <code>treasure_classes</code>) and the remainder of the path is used as the item's display/internal name (available in the EJS scope as <code>itemTitle</code>). The matching template in <code>Pages/dynamic/</code> looks up the item by name (case-insensitive) and renders it. For a relic, the template looks like this:</p>

<pre><code>&lt;% const relic = allRelics.find(r => (getEnLoc(r.nameLocalizationKey) || r.name).toLowerCase() === itemTitle.toLowerCase()); %&gt;
&lt;% if (relic) { %&gt;
    &lt;%- await createRelicTemplate(relic, allAffixData, allSkills) %&gt;
    &lt;%- await createRelicByBossTemplate(relic, allDungeons, allTCs, allRelics, devotionPoints) %&gt;
&lt;% } else { %&gt;
    &lt;p&gt;Relic not found: &lt;%= itemTitle %&gt;&lt;/p&gt;
&lt;% } %&gt;
</code></pre>
<p>Note: a static page created at <code>Pages/&lt;name&gt;.txt</code> always takes priority over a dynamically generated page with the same name.</p>

<h2>Devotion Points System</h2>
<p>In the sidebar, you can input your character's devotion points for Fury, Faith, and Discipline. These points can increase the drop chance of relics that have an affinity for your highest devotion.</p>

The calculation is as follows:
<ul>
    <li>The system identifies your highest devotion (Fury, Faith, or Discipline).</li>
    <li>If there is a single highest devotion (no ties) and the point value is greater than 4, a bonus is applied.</li>
    <li>The bonus multiplier is calculated as <code>2 + 0.1 * (points - 4)</code>. For example, 10 points in Fury gives a <code>2 + 0.1 * (10 - 4) = 2.6x</code> multiplier.</li>
    <li>This multiplier is applied to the weight of relics that have an affinity for your highest devotion, increasing their drop chance from treasure classes.</li>
    <li>The "Your Chance" column in the tables reflects this adjusted probability.</li>
</ul>
